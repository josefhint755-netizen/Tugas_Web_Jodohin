
# Jodohin Backend

Backend aplikasi Jodohin dibuat menggunakan NestJS untuk mengelola data profil pengguna melalui REST API.

## Teknologi
- NestJS
- TypeScript
- Node.js

## Fitur
- Menampilkan seluruh profil
- Menampilkan detail profil berdasarkan ID
- Menambahkan profil baru
- Mengubah data profil
- Menghapus profil

## Endpoint API

| Method | Endpoint | Fungsi |
|---|---|---|
| GET | /profil | Menampilkan semua profil |
| GET | /profil/:id | Menampilkan detail profil |
| POST | /profil | Menambahkan profil |
| PATCH | /profil/:id | Mengubah profil |
| DELETE | /profil/:id | Menghapus profil |

## Cara Menjalankan

1. Install dependencies: `npm install`
2. Jalankan backend: `npm run start:dev`
3. Backend berjalan di `http://localhost:3000`
